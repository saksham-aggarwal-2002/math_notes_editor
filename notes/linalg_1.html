Linear Algebra

The goal here is to develop an algebraic theory for linear maps.

Vector Spaces and Linear Maps

Vector space algebra codifes the flat “arrow” behaviour in Euclidean space (vector addition and scalar multiplication). They are not algebraically interesting themselves, but the minimal structure required to define linear maps.

(Vector Space)

A vector space is a quadruple \((V,F,+,\cdot)\) where:

  • \((V,+)\) is an abelian group
  • \((F,+,\cdot)\) is a field
  • \(\cdot:F\times V\to V\) is scalar multiplication satisfying, for all \(a,b\in F\) and \(u,v\in V\):
    • \(a(u+v)=au+av\) (Distributive over vectors)
    • \((a+b)v=av+bv\) (Distributive over scalars)
    • \((ab)v=a(bv)\) (Associativity)
    • \(1v=v\) (Identity)

The maps which preserve the above structure are exactly the linear maps. The algebraic conditions are meant to encode the “linearity” between inputs and outputs, if we scale and add (linear combination) input vectors, then a linear map preserves those operations (same linear combination) on the output vectors.

(Linear Map)

Let \(V,W\) be vector spaces over \(F\). A map \(T:V\to W\) is linear if, for all \(u,v\in V\) and \(a\in F\),

  • \(T(u+v)=T(u)+T(v)\) (respects vector addition)
  • \(T(av)=aT(v)\) (respects scalar multiplication)

Next common algebraic motif is to consider vector subspaces:

(Vector Subspace) For a vector space \(V\), a subset \(U\subseteq V\) is a vector subspace if \(U\) is itself a vector space under the operations inherited from \(V\). Equivalently, \(U\) is a subspace iff:

  • \(0\in U\) (0 vector is in subspace)
  • \(u,v\in U \implies u+v\in U\) (Closed under addition)
  • \(a\in F,\ u\in U \implies au\in U\) (Closed under scalar multiplication)

Vector subspaces in \(\mathbb{R}^n\) are easy to understand as all lower-dimensional hyperplanes through the origin:

A linear map creates two important vector subspaces in the domain and co-domain:

(Kernel and Image)

Let \(T:V\to W\) be a linear map.

  • Kernel: \(\ker T=\{v\in V:T(v)=0\}\subseteq V\)
  • Image: \(\operatorname{im}T=\{T(v):v\in V\}\subseteq W\)

\(\ker T\) is a subspace of \(V\) and \(\operatorname{im}T\) is a subspace of \(W\).

Generating Sets

Basis and Dimension

As is a common motif in the study of algebraic structures, we ask if there is a smaller set that can generate the whole space. This leads us to the following definitions:

(Span and Linear Independence)

  • Span: The set of all linear combinations of a set of vectors \(S\): \[\operatorname{span}(S)=\left\{\sum_{i=1}^k a_i v_i : a_i\in F,\ v_i\in S\right\}.\]

  • Linear independence: A set of vectors is linearly independent if no vector in the set can be written as a linear combination of the others. Equivalently if the following holds: \[\sum_{i=1}^n a_i v_i=0 \implies a_1=\cdots=a_n=0\] See Intuition

visualisation of span and L.I

So a spanning set is just a generating set and a linearly independent set doesn’t have any redundancy. Taking a set that is spanning and linearly independent gives us the basis:

(Basis and Dimension)

  • A linearly independent spanning set of \(V\) is called a basis
  • If \(B\) is a basis for vector space \(V\) then \(\dim(V)=|B|\)
    • Well-defined since any two bases of a vector space can be shown to have same cardinality
    • \(V\) is said to have infinite dimension if it has no finite basis

Hence, the basis is not unique but the dimension is:

R2 with difference basis vector sets but same dimension

In fact, it can be shown that any two vector spaces with the same dimension are isomorphic.

(Isomorphism and Dimension)

Let \(V\) and \(W\) be vector spaces over the same field. If \[ \dim(V)=\dim(W), \] then \(V\) and \(W\) are isomorphic.

Some Useful Results

Some useful results relating to above ideas include:

(Dimension of Quotient Space)

Let \(V\) be a finite-dimensional vector space and \(U\subseteq V\) a subspace. If \(\dim V=n\) and \(\dim U=m\) then

\[ \dim(V/U)=\dim V-\dim U = n-m \]

(Rank-Nullity Theorem)

Let \(T:V\to W\) be linear with \(V\) finite-dimensional Then

\[ \dim V = \underbrace{\dim\ker T}_{\text{nullity}} + \underbrace{\dim\operatorname{im}T}_{\text{rank}} \]

(Injectivity and Surjectivity Characterisations)

Let \(T:V\to W\) be linear.

  • \(T\) is injective iff \(\ker T=\{0\}\)
  • \(T\) is surjective iff \(\operatorname{im}T=W\)

If \(V\) and \(W\) are finite-dimensional:

  • \(T\) is injective iff \(\operatorname{nullity}(T)=0\)
  • \(T\) is surjective iff \(\operatorname{rank}(T)=\dim W\)
  • \(T\) is injective iff \(T\) is surjective iff \(T\) is bijective (assuming dim \(V\) = dim \(W\))

Finite-Dimensional Coordinate System

Suppose we have a finite dimensional vector space. So we’ve found a finite set of vectors which generate the whole space (summarises the algebraic structure). Hence, given a basis, we can define a coordinate system as an orientation to that generating system.

(Coordinate Vector Representation)

Let \(V\) be an \(n\)-dimensional vector space over \(F\) and let \(B=\{v_1,\dots,v_n\}\) be a basis of \(V\). Every \(v\in V\) can be written uniquely as

\[ v=\sum_{i=1}^n a_i v_i. \]

The coordinate vector of \(v\) with respect to \(B\) is

\[ [v]_B=(a_1,\dots,a_n)^\top\in F^n. \]

(Matrix Representation)

Let \(T:V\to W\) be linear, with \(B=\{v_1,\dots,v_n\}\) a basis of \(V\) and \(C=\{w_1,\dots,w_m\}\) a basis of \(W\). The matrix of \(T\) with respect to \(B\) and \(C\) is the \(m\times n\) matrix \([T]_{C\leftarrow B}\in F^{m\times n}\) whose \(j\)-th column is the coordinate vector \([T(v_j)]_C\):

\[ [T]_{C\leftarrow B} = \begin{pmatrix} \vert & & \vert \\ [T(v_1)]_C & \cdots & [T(v_n)]_C \\ \vert & & \vert \end{pmatrix} \]

For all \(v\in V\) the matrix satisfies:

\[ [T]_{C\leftarrow B}\,[v]_B = [T(v)]_C \]

(Matrix Operations Encode Linear Map Operations)

Let \(T_A, T_B\) be linear transformations and \(A, B\) be their matrices w.r.t some bases. Then:

  • \(AB = T_A \circ T_B\)
  • \(A+B = T_A + T_B\)
  • \(\lambda A = \lambda T_A\)
  • \(A^{-1} = T_A^{-1}\)

Change of Basis

(Change Of Basis Matrix)

Let \(V\) be an \(n\)-dimensional vector space and let \(B=\{v_1,\dots,v_n\}\) and \(B'=\{v'_1,\dots,v'_n\}\) be ordered bases of \(V\). The change-of-basis matrix from \(B\) to \(B'\) is the \(n\times n\) matrix \(P_{B'\leftarrow B}\) whose \(j\)-th column is the coordinate vector of \(v_j\) with respect to \(B'\):

\[ P_{B'\leftarrow B}=\begin{pmatrix} [v_1]_{B'} & \cdots & [v_n]_{B'} \end{pmatrix}. \]

For every \(v\in V\) we have

\[ [v]_{B'} = P_{B'\leftarrow B}\,[v]_B. \]

See Working Example

(Change Of Basis Matrix iff Invertible Matrix)

Let \(V\) be an \(n\)-dimensional vector space.

  • If \(B\) and \(B'\) are ordered bases of \(V\), then the change-of-basis matrix \(P_{B'\leftarrow B}\) is invertible and

    \[ (P_{B'\leftarrow B})^{-1} = P_{B\leftarrow B'}. \]

  • Conversely, any invertible \(n\times n\) matrix \(P\) over \(F\) is the change-of-basis matrix \(P_{B'\leftarrow B}\) for some ordered bases \(B,B'\) of \(F^n\).

(Similar Matrices)

Two \(n\times n\) matrices \(A\) and \(B\) over \(F\) are similar if there exists an invertible \(n\times n\) matrix \(P\) such that

\[ B = P^{-1} A P. \]

For finite-dimensional vector spaces, if we show a matrix property to be invariant up to change of basis (same for similar matrices), then we’ve essentially shown the property to be of the underlying linear map.

Determinant

The determinant is a quantity associated with a linear map between vector spaces of the same finite dimension. This quantity measures the factor by which “area” scales under a linear transformation.

Structure of Linear Operators

The space of \(T: V \to V\) linear operators, \(\operatorname{End}(V)\) is very interesting algebraically. In this space, it makes sense to study invariant subspaces:

(T-Invariant Subspace)

Let \(T:V\to V\) be linear. A subspace \(U\subseteq V\) is \(T\)-invariant if \(T(U)\subseteq U\), equivalently:

\[ u\in U\ \implies T(u)\in U\]

Example of big invariant subspace, and another smaller invariant piece sitting inside it.

The smallest invariant subspace is \(1\)-dimensional and hence looks like a line. This gives rise to eigenvalues and eigenvectors:

(Eigenvalue and Eigenvector)

Let \(T:V\to V\) be linear. If for some scalar \(\lambda\in F\) and \(v \in V\) (\(v\) cannot be \(0\) vector):

\[T(v)=\lambda v\]

Then \(\lambda\) is called an eigenvalue and \(v\) is corresponding eigenvector.

Finite-Dimensional Diagonalization

Now suppose if the vector space is a finite \(n\)-dimensional vector space. If we find \(n\) linearly independent eigenvectors, then we can construct a basis for \(V\) in terms of those eigenvectors which decomposes the action of \(T\) as pure scalar multiplication on independent eigendirections. This is diagonalization:

(Diagonalization and Diagonalizability) Let \(V\) be an \(n\)-dimensional vector space over \(F\). Then \(T: V \to V\) is diagonalizable:

  • If \(T\) can be expressed as a diagonal matrix \(D=\operatorname{diag}(\lambda_1,\dots,\lambda_n)\) by choice of some basis \(B\): \[ [T]_B = D \]

  • In matrix language, \(T\) is diagonalizable if for any matrix representation A, we can find an invertible matrix \(P\) such that:

    \[ A = P\,D\,P^{-1} = \begin{pmatrix} | & & | \\ v_1 & \cdots & v_n \\ | & & | \end{pmatrix} \left(\begin{matrix}\lambda_1 & & 0\\ & \ddots & \\ 0 & & \lambda_n\end{matrix}\right) \begin{pmatrix} | & & | \\ v_1 & \cdots & v_n \\ | & & | \end{pmatrix}^{-1} \]

Note that columns of \(P\) are linearly independent eigenvectors of \(T\) and a basis of \(V\).

See Working Example

Note that a specific diagonalization is not required to be unique! The diagonal matrix D is unique up to permutation of basis eigenvectors.

We can choose different eigenvectors in a 2d space giving different Ps.

Performing Diagonalization

Characteristic polynomial. It is invariant under change of basis, which makes sense.

Eigenvalues are roots of this polynomial in F. Hence, the goal of finding eigenvalues is equivalent to finding roots of degree \(n\) polynomials in the field \(F\).

Eigenvectors live in ker(T - lamda*I) = Eigenspace.

Eigenvalues do not “mix”. Hence, we just find the basis of each eigenspace and union it together.

(Distinct Eigenvalues Give Linearly Independent Eigenvectors) Let \(V\) be a vector space over \(F\) and let \(T:V\to V\) be linear. Suppose \(\lambda_1,\dots,\lambda_k\in F\) are distinct eigenvalues and \(\{v_1,\dots,v_k\}\) are their corresponding eigenvectors. Then \(\{v_1,\dots,v_k\}\) are linearly independent.

But note that the converse of the above theorem is not true, the same eigenvalue can have linearly independent eigenvectors. Take any uniform scaling matrix as an example.

Diagonalization Guaranteed?

Now the natural question becomes - when is it possible to diagonalize an operator \(T\)? The question is equivalent to asking, when are we guaranteed to have \(n\) linearly independent eigenvectors?

  • Potential issue 1: We need characteristic polynomial to have at least 1 eigenvalue.
    • When F = C this problem is solved by the fundamental theorem of algebra.
    • Over R this is not automatically true.

Rotations in R^2 have complex eigenvalues.

  • Potential issue 2: Even if we have at least 1 eigenvalue, we may not have sufficient linearly independent eigenvectors. We need to ensure that eigenvalue contributes sufficient linearly independent eigenvectors to diagonalize \(T\). That is: \[ \sum_{\{ \text{number of distinct eigenvalues} \}}{\operatorname{dim} \operatorname{ker} (T - \lambda_i I)} = n \]

We start by asking, what is the maximum number of linearly independent eigenvectors a specific eigenvalue can contribute? This is the algebraic multiplicity:

Over \(\mathbb{C}\), the algebraic multiplicity is always \(n\). Hence:

T is diagonalizable iff geometric multiplicity = algebraic multiplicity theorem.

The above theorem is the best we can do because unfortunately, linear transformations allow for geometric multiplicity < algebraic multiplcity. These are exactly the “shearing” transformations:
